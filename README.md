# ESF-2 Bingo

Bingo cards for Emergency Support Function #2 (Communications) activations. Each one is a single HTML file with no build step and no dependencies other than Google Fonts.

| File | What it is |
|---|---|
| `index.html` | Landing page that links to both editions |
| `classic.html` | **ESF-2 Activation Bingo**: the professional edition (columns spell C-O-M-M-S) |
| `unhinged.html` | **ESF-2 Bingo: Unhinged Edition**: the hour-31 edition (columns spell H-E-L-P-!) |

## How to play
- Tap **New card** (or **Deal new chaos**) so each player gets a different random card.
- Tap a square when it happens. Five in a row (row, column or diagonal) wins.
- Each card and its marks are saved in that player's browser. Nothing is shared between devices.

## Editing the squares
Each file has a `POOL` array near the top of its `<script>` block. Add, remove or reword entries there. You need at least 24 entries.

## Hosting
Turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) to get a shareable URL.

*Not an official ODEM product.*
